


功能：
   1. 有多种颜色的绸缎。红色，蓝色，绿色,黑色,金色,银色
      1.1 红色: 圆形运动。
      1.2 蓝色: 钩锁(玩家快速移动)
      1.3 绿色: 伸缩(反弹子弹)
      1.4 黑色: 桥梁或者墙壁 (最坚固)
      1.5 金色: 拉取物体
      1.6 银色: 弹簧
   2. 损耗:
      1. 红色 使用完后 可回收 50%
      2. 蓝色 使用完后 可全部回收
      3. 绿色 反弹3个子弹 -1
      4. 黑色 持续时间为长度 * 5 秒，可回收 30%
      5. 金色 长度每次抓取 损耗 10%
      6. 银色 不可回收
   3. 特殊说明
      1. 红色 蓝色 在中途 可以使用其他 绸缎，但是会受绸缎范围的限制。
      2. 任何绸缎都能 抵挡子弹，会受剪刀，转换器等的影响。
      3. 转换器 转换后，会改变绸缎的颜色以及相关性质，持续一段时间。
      4. 红色 可以在摆动过程中 射出第二根红色的线，此时 轨迹会变成 椭圆。
      5. 蓝色 钩锁 在移动过程中 射出蓝色线，此时 会回收当前的蓝线。
